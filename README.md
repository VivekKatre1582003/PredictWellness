# [PredictWellness](https://predictwellness.onrender.com/)

**PredictWellness** is a machine learning-based platform that helps predict an individual's overall wellness based on various health parameters. It takes into account factors such as physical activity, mental health, sleep patterns, and nutrition to generate a wellness score. The platform also uses **Large Language Models (LLMs) with Google GenAI** to understand and respond to users' health and wellness-related queries, providing personalized, conversational guidance and recommendations.

The goal is to provide users with personalized insights, wellness predictions, and AI-powered recommendations for improving their overall well-being.

## Features

* **Wellness Score Prediction**: Predicts an individual’s wellness score based on various health parameters.
* **Data Logging**: Allows users to log daily wellness-related data such as exercise, diet, sleep, and mood.
* **Personalized Recommendations**: Provides customized wellness improvement suggestions based on the user's data.
* **AI-Powered Query Assistant**: Uses **LLM technology and Google GenAI** to understand user queries and provide relevant, conversational responses related to health and wellness.
* **Interactive AI Guidance**: Users can ask wellness-related questions and receive AI-generated answers based on their queries.
* **User-friendly Interface**: Simple and intuitive interface for easy interaction.

## Technologies Used

* **Python**: Main programming language for backend development.
* **Flask/Django**: Web framework used for creating the application and managing backend functionality.
* **scikit-learn**: Machine learning library used for building the wellness prediction model.
* **Google GenAI**: Used to integrate generative AI capabilities and power the LLM-based conversational assistant.
* **Large Language Model (LLM)**: Used to understand user queries and generate contextual wellness-related responses.
* **Pandas**: Data manipulation and analysis.
* **Matplotlib/Seaborn**: Data visualization and exploratory data analysis.
* **SQLite/PostgreSQL**: Database for storing user and wellness-related data.
* **HTML/CSS/JavaScript**: Front-end development.

## AI Integration

PredictWellness combines **Machine Learning and Generative AI** to provide a more interactive wellness experience:

1. **Machine Learning Model** analyzes the user's health and lifestyle parameters to predict a wellness score.
2. **Google GenAI / LLM** processes users' natural-language wellness queries.
3. The AI assistant generates **personalized, conversational responses and recommendations** based on the user's query and available wellness information.
4. This allows users to interact with the application not only through structured data inputs but also through a **natural-language AI assistant**.
